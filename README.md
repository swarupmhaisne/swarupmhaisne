## 🚀 Featured Projects

### 🎥 Meetora — Real-Time Video Conferencing Platform
> *React · Node.js · Express.js · MongoDB · Socket.IO · WebRTC · Material UI*

Built a **full-stack video conferencing app** with zero third-party video SDKs — raw WebRTC, a custom signalling server, and Socket.IO for real-time coordination.

**What makes it stand out:**
- 🔗 Implemented the **WebRTC signalling flow from scratch** — SDP offer/answer exchange and ICE candidate coordination over Socket.IO
- 💬 Real-time in-meeting **chat with message history** replayed to late joiners (in-memory relay)
- 🖥 **Screen sharing**, camera/mic toggle, and participant join/leave notifications
- 🔐 Secure auth with **bcrypt-hashed passwords** and `crypto.randomBytes` session tokens
- 📅 Persistent **meeting history** per authenticated user (MongoDB)
- 🛡 `withAuth` HOC for protected route guarding on the frontend

### 🗂 WorkNexa — Multi-Tenant Project Management SaaS
> *React · Redux Toolkit · Express.js · PostgreSQL · Prisma · Tailwind CSS · Clerk · Inngest*

Built a **full-stack project management platform** with multi-workspace support, role-based access, analytics dashboards, and **automated email reminders** via durable background jobs.

**What makes it stand out:**
- 🏗 **Multi-tenant architecture** — Workspace → Project → Task → Comment hierarchy with cascade deletes
- 🔐 **Clerk-synced identity** — user and workspace data auto-synced from Clerk webhooks via Inngest event functions (no polling)
- ⏰ **Durable due-date reminders** — `Inngest step.sleepUntil(due_date)` schedules a per-task reminder email without any cron jobs
- 📊 **Recharts analytics** — BarChart + PieChart for task status, type, and priority breakdowns
- 📅 **Custom calendar view** — built with `date-fns`, pins tasks to due dates, highlights overdue
- 🛡 **RBAC** — Admin vs Member at workspace level; team_lead gate on task creation/deletion
- 🗄 **Serverless Postgres** — NeonDB with `@prisma/adapter-neon` for edge-compatible connection pooling

[![View Repo](https://img.shields.io/badge/View%20Repo-WorkNexa-8b5cf6?style=flat-square&logo=github)](https://github.com/swarupmhaisne/project-management-)
